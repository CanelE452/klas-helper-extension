# 미수강 강의 읽기 전용 모니터

기존 KLAS 로그인 세션으로 **마감 전·지난 공개 미완료 강의**를 함께 조회합니다.
과목·강의명·진도·마감 한국시간·강의별 조회시각을 표시하고, 명시적으로 저장한
JSON 파일을 Codex/dot의 로컬 작업 도구로 읽을 수 있습니다.

원본 KLAS Helper의 전체 확장과 별개인 **`dist-monitor` 전용 빌드**를 사용하세요.
이 패키지는 영상·출석·인증 우회·과제 제출 코드를 실행하지 않습니다. KLAS 홈에서
조회 버튼을 누를 때 강의 목록 조회 API 하나만 호출합니다. 외부 서버 전송,
비밀번호·학번·쿠키 수집, 세션 연장, 브라우저 저장소, 백그라운드 작업은 없습니다.

## 준비 및 빌드

Node.js 18 이상과 npm이 필요합니다. 저장소 루트에서 실행하세요.

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd test
npm.cmd run lint:monitor
npm.cmd run build:monitor
```

결과는 `dist-monitor/manifest.json`, `monitor.js`, `LICENSE` 세 파일입니다.
일반 `npm run build`의 `dist`는 원본 전체 확장 빌드이므로 이번 용도로 로드하지 마세요.
잠금 파일 의존성은 원본 그대로이며 새로운 런타임 패키지를 추가하지 않았습니다.

## Chrome에 적용

1. 개발자 모드의 확장 설치는 Chrome의 KLAS 홈 접근 권한을 새 코드에 부여합니다.
   에이전트가 대신 설치할 때는 **이 패키지에 대한 설치 시점 승인**을 먼저 받아야 합니다.
   사용자가 직접 설치해도 됩니다.
2. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를
   눌러 `dist-monitor` 폴더를 선택합니다. ZIP을 받았다면 먼저 압축을 해제합니다.
3. KLAS의 `https://klas.kw.ac.kr/std/cmn/frame/Frame.do` 홈으로 갑니다.
   로그인은 사용자가 KLAS 화면에 직접 입력합니다. 비밀번호를 채팅이나 파일로 보내지 마세요.
4. 홈을 새로고침하고 수강 과목 로딩을 기다린 뒤 **강의 현황 조회**를 누릅니다.
5. 조회시각·마감·부분 실패 메시지를 확인합니다. **JSON 스냅샷 저장**을 누르면
   `klas-monitor.snapshot.json`이 기본 다운로드 위치에 저장됩니다.

Chrome 111 이상을 대상으로 합니다. content script는 해당 홈 경로에서 `MAIN` world로
실행되어 페이지의 `appModule.atnlcSbjectList`를 읽습니다. KLAS 페이지 스크립트와 같은
실행 환경이므로 이 결과는 학교의 공식 출석 판정을 대신하지 않습니다. 페이지의 앱 구조나
인증 방식이 변경되면 실사용 확인 및 수정이 필요할 수 있습니다.
배포 권한은 [Chrome content scripts 문서](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts#static-declarative)를 참고했습니다.

## Codex/dot에서 읽기

이 구현은 **수동 스냅샷 연결**입니다. MCP 서버 생성·등록, 실시간 연결, 자동 모니터링,
예약 알림은 구성하지 않았습니다. 이 작업에서 실제로 검증한 연결은 다음입니다.

`Chrome 가상 데이터 조회 → JSON 다운로드 → 로컬 Node CLI 실행 → 현황 요약`

로컬 실행 도구가 있는 Codex/dot에서 다음을 실행합니다.

```powershell
node scripts/read-monitor.cjs "C:/Users/User/Downloads/klas-monitor.snapshot.json"
```

다른 작업 폴더에서는 스크립트에도 절대 경로를 사용하세요. dot에 요청할 때는 예를 들어
“로컬 작업 도구로 아래 스크립트와 내 스냅샷 파일을 읽어서 마감 전·지난 미수강과
조회시각을 알려줘”라고 파일 경로를 지정하면 됩니다. 이 dot에 직접 로컬 실행 도구가
없으면 로컬 작업 위임 기능이 필요합니다. 도구가 없는 환경에서 MCP 호출이 가능한 것처럼
해석하면 안 됩니다.

출력의 `capturedAt`과 `observedAt`은 KLAS 조회시각이고 `asOf`는 파일을 읽은 시각입니다.
판독기는 읽는 시각 기준 마감을 다시 분류하지만 **진도는 마지막 조회시점 값**입니다.
15분 넘은 파일은 `stale: true`입니다. 최신 상태가 필요하면 브라우저에서 다시 조회·저장한
파일을 읽습니다. 다운로드를 반복하면 Chrome이 파일명에 `(1)` 등을 붙일 수 있으니 최신
파일을 명시하세요. 어떤 파일도 자동으로 검색·감시하거나 외부로 업로드하지 않습니다.

## 오류와 데이터 해석

- 로그인 만료·리다이렉트·로그인 HTML: `auth-required`. KLAS에서 직접 재로그인합니다.
- 오프라인·15초 타임아웃·잘못된 JSON/배열: 과목별 실패를 기록합니다. 일부 성공은
  `partial`; 전체 실패는 현재 0건으로 표시하지 않습니다.
- 화면에서 재조회 실패 시 이전 결과와 원래 조회시각을 유지하며 오래된 결과임을
  표시하고 내보내기를 막습니다. 학기·수강목록 변경 시 결과를 비웁니다.
- 수강목록이 아직 비어 있으면 조회하지 않습니다. 실제 수강이 없는 경우와 로딩 중인
  경우를 구분할 검증된 신호가 없어 “수강 과목 확인 불가”로 표시합니다.
- 진도 `100`/`"100"`은 완료, `OFF` 및 강의 이외 항목은 제외합니다. 잘못된 진도·마감은
  확인 불가 및 부분 결과로 표시합니다. 과목+학기로 중복 요청을 제거합니다.
- 강의 고유 ID의 응답 필드는 아직 실계정으로 확인하지 못했습니다. 같은 제목의 다른
  차시를 잃지 않도록 행을 보존하므로 서버의 실제 중복 행은 중복 표시될 수 있습니다.
  행 키는 두 스냅샷 간 강의 식별 용도로 사용하지 마세요.
- 시간대 없는 마감은 한국시간입니다. 분 단위 마감은 마지막 초까지 포함합니다
  (`:59.999`). 정확히 마감시각인 순간은 마감 전, 다음 밀리초부터 마감 지남입니다.
- 과목 100개·전체 강의 10,000개·JSON 2MiB 한도를 둡니다. 전체 행 수 초과 과목은
  부분 실패로 표시하며, 저장 결과가 2MiB를 넘으면 저장을 중단합니다.

제목은 `sbjt/sdesc/title`, 마감은 `endDate/expiredate/expireDate`를 지원합니다.
원본의 `home.js`와 [KLAX 공개 조회 코드](https://github.com/goonbam0306/klax/blob/65cf39c4b624702a4e3d5f8ef13b0ecb9c9b5b78/src/klax/client.py#L722-L738)를 참고했습니다.
KLAX를 설치·실행하지 않았으며 자격증명 저장 방식도 사용하지 않습니다. 실계정 API의
현재 필드·홈 DOM 호환성은 설치·로그인 후 최종 확인해야 합니다.

## 개인정보와 해제

원본 API 객체 대신 허용한 수업 현황 필드만 내보냅니다. 수업명과 진도도 개인 정보이므로
다운로드 파일은 비공개로 보관하세요. 저장소 안에 저장하지 마세요. `*.snapshot.json`과
빌드 산출물은 Git에서 제외하지만 다른 이름으로 저장한 개인정보까지 자동 보호하지는
않습니다. 실제 파일이나 원본 응답을 이슈/PR/공개 로그에 붙이지 마세요.

모니터를 끄려면 `chrome://extensions`에서 **KLAS Read-only Lecture Monitor**를 사용
중지하거나 제거합니다. 저장한 파일은 사용자가 직접 관리합니다. OS 서비스·예약 작업·
실행 중 MCP 프로세스가 없으므로 별도 백그라운드 해제 절차는 없습니다.

검증 내역과 남은 적용 단계는 [docs/monitor-verification.md](docs/monitor-verification.md)에 있습니다.
